# Sistema Financeiro - Instalacao Linux Ubuntu

## Uso local

1. Extraia este pacote.
2. Abra um Terminal na pasta `Aplicativo`.
3. Execute:

   ```bash
   chmod +x "Abrir Sistema Financeiro.sh"
   ./Abrir\ Sistema\ Financeiro.sh
   ```

4. Acesse `http://127.0.0.1:8010` no navegador.

## Uso em rede

Execute `Abrir Sistema Financeiro na Rede.sh` ou acesse diretamente:

`https://sistema-financeiro.net:8030`
